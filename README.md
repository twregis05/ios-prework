# Prework - *iOS Introductory App*

Submitted by: **Trenton Regis**

**iOS Introductory App** is an app that allows the user to change the background color to randomly 
generated color upon clicking the "Change Background" button. Also gives a little bit of insight 
about me, the school I go to, and my career aspirations.

Time spent: **1/2** hours spent in total

## Required Features

The following **required** functionality is completed:

- [ ] Users are see a screen with three labels and a button
- [ ] Tapping the button changes the screen color to a random color
